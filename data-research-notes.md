# Real-data rebuild — research notes

The first ingestion release uses four official sources. O*NET 30.3 is available as CSV, JSON, SQL, RDF, and web services; its program states that the database is updated quarterly and that the database is Creative Commons licensed. The source archive exposes occupation data, task statements, essential skills, work activities, software skills, work context, job zones, and alternate titles.

ESCO v1.2.1 is downloadable in CSV, RDF, TTL, ODS, XML, and JSON-LD, with a semantic model based on RDF/OWL/SKOS. Its download flow can require an email step, so the first automated release does not depend on ESCO being silently scraped; the pipeline records ESCO as an optional source package and supports a later user-provided download.

The U.S. Census publishes NAICS 2022 structure as XLSX. The UN Statistics Division publishes ISIC Rev. 5 structure as CSV. The Bureau of Labor Statistics publishes May 2025 OEWS national data as an official ZIP/XLSX archive. Direct command-line retrieval of the BLS archive returned HTTP 403 in this environment, but the official page download succeeded through the browser and was preserved in `data/raw/bls_oesm25nat.zip`; the update workflow should retain a browser-download fallback or use the BLS public data files/API if the host blocks automated requests.

The BLS OEWS tables page currently lists May 2025 national, state, metropolitan/nonmetropolitan, national industry-specific, and all-data downloads. The national industry-specific archive is exposed as `/oes/special-requests/oesm25in4.zip`; the current working bundle includes the national archive because it was the first download completed successfully. The UI must show the OEWS vintage and distinguish cross-industry estimates from industry-specific estimates.

For free operation, the recommended architecture is a static frontend with precomputed JSON and a separate refresh workflow. Cloudflare Pages advertises a free plan with unlimited static requests and bandwidth, unlimited sites, and 500 builds/month; GitHub Actions supports scheduled workflows with cron syntax. This keeps the live site fast and avoids making the user's laptop compute the graph on every visit. The refresh job should download source archives, validate checksums/schema, build compact JSON, and deploy only when the data release passes validation.

Important integrity boundary: the official sources do not provide one universal industry-to-occupation parent-child tree. The product must preserve separate taxonomy trees and only add crosswalk edges when a source explicitly supports them. Any derived semantic similarity, clustering, or work-rhythm synthesis must be labeled as derived or unavailable rather than presented as observed fact.

Verification: the live preview returned HTTP 200 for `manifest.json`, `taxonomies.json`, and `occupations.json`; the manifest reported release `20260814`, 1,016 occupations, 18,796 task statements, 961 O*NET/BLS SOC joins, 2,125 NAICS records, 830 ISIC records, and zero synthetic records. The ISIC toggle rendered real section, division, group, and class records in the browser. A React hook-order error briefly appeared after lifting selected occupation state; it was fixed by making the state hook unconditional, and typecheck/build passed afterward.
